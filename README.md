📡 Amateur Radio Telescope — HI 1420 MHz

Любительский радиотелескоп для наблюдения радиолинии нейтрального атомарного водорода на частоте 1420,40575177 МГц.

Проект представляет собой экспериментальную радиотехническую систему, построенную на основе спутниковой параболической антенны, самодельного облучателя, малошумящего усилителя и программно-определяемого радиоприёмника RTL-SDR.

Основная задача — попробовать зарегистрировать спектральную линию нейтрального водорода в межзвёздной среде, изучить принципы радиоастрономии и создать доступную платформу для дальнейших экспериментов.

«Статус проекта: экспериментальная разработка. Расчёты, схемы и программное обеспечение находятся в процессе совершенствования. Возможность регистрации HI-линии конкретной конфигурацией оборудования пока не гарантируется.»

---

🌌 1. О проекте

На частоте приблизительно 1420,4 МГц находится спектральная линия нейтрального атомарного водорода (HI).

Она возникает вследствие сверхтонкого перехода между двумя состояниями основного энергетического уровня атома водорода.

Радиолиния HI имеет особое значение для радиоастрономии: по её спектру можно изучать распределение нейтрального водорода в нашей Галактике, а также исследовать его движение по доплеровскому смещению.

Цель проекта — создать компактный радиотелескоп, способный:

- Принимать радиосигналы в районе 1420 МГц.
- Регистрировать спектр принимаемого излучения.
- Искать спектральную линию нейтрального водорода.
- Сравнивать спектры разных направлений неба.
- Исследовать изменение спектрального профиля.
- В перспективе создавать простые карты распределения HI.

Основные направления развития

Направление| Описание

🔧 2. Аппаратная часть

Система состоит из нескольких основных блоков.

2.1. Антенна

В качестве основной антенны используется спутниковая параболическая тарелка диаметром около 55 см.

Предполагаемая конструкция:

- Параболический отражатель.
- Самодельный облучатель BiQuad.
- Крепление облучателя в районе фокуса.
- Возможность изменения направления антенны.

Облучатель BiQuad

BiQuad — направленная антенна, состоящая из двух соединённых квадратных рамок.

Расчётная длина стороны одного квадрата для частоты 1420 МГц:

[
\lambda = \frac{c}{f}
]

[
\lambda \approx 21,1\text{ см}
]

[
L \approx \frac{\lambda}{4} \approx 5,28\text{ см}
]

Это начальный геометрический расчёт. Реальные размеры могут корректироваться с учётом толщины проводника, зазора питания, рефлектора и согласования.

Положение облучателя необходимо определять с учётом фактической геометрии параболического отражателя. Для офсетной тарелки нельзя автоматически использовать формулу фокусного расстояния симметричной параболы.

2.2. Малошумящий усилитель

В проекте рассматривается использование LNA на микросхеме BGA2869.

Назначение усилителя:

- Усиление слабого сигнала антенны.
- Снижение влияния последующих потерь кабеля на общую чувствительность системы.
- Обеспечение достаточного уровня сигнала для дальнейшей обработки.

LNA желательно размещать максимально близко к облучателю.

Важно: характеристики усилителя, указанные производителем или продавцом для других частот, нельзя автоматически переносить на 1420 МГц. Реальные коэффициент усиления и коэффициент шума на рабочей частоте требуют проверки.

2.3. Фильтрация

В радиотракте предусматривается возможность использования SAW-фильтра с рабочей полосой около 1420 МГц.

Предполагаемое расположение:

- После LNA.
- Перед RTL-SDR.

Фильтр предназначен для подавления внеполосных сигналов, которые могут перегружать приёмник.

Его применение зависит от реальной помеховой обстановки и характеристик конкретного фильтра.

Необходимо учитывать:

- Центральную частоту.
- Полосу пропускания.
- Вносимые потери.
- Подавление внеполосных сигналов.
- Допустимую входную мощность.

2.4. Кабельная система

В проекте используются коаксиальные кабели с волновым сопротивлением 50 Ом.

Предполагаемая конфигурация:

Участок| Кабель| Длина
BiQuad → LNA| RG-316| 30 см
LNA → фильтр| RG-58| 1–2 м
Фильтр → RTL-SDR| RG-316 или RG-58| Минимально необходимая

RG-316 выбран для короткого соединения с облучателем благодаря компактности и гибкости.

RG-58 используется на участке после усилителя, где кабельные потери уже менее критичны для общей чувствительности системы.

Ориентировочные потери на 1420 МГц:

Кабель| Длина| Ориентировочные потери
RG-316| 30 см| 0,3–0,4 дБ
RG-58| 1 м| 0,5–0,7 дБ
RG-58| 2 м| 1–1,4 дБ

Значения зависят от производителя, конструкции кабеля и качества разъёмов.

2.5. SDR-приёмник

В качестве приёмника используется RTL-SDR Blog V4.

Он обеспечивает:

- Настройку центральной частоты.
- Приём IQ-отсчётов.
- Получение спектра сигнала.
- Изменение частоты дискретизации.
- Программную обработку сигнала.

RTL-SDR подключается к компьютеру через USB.

💻 3. Программная часть

Основная обработка данных выполняется на компьютере с использованием Python.

Программная система предназначена для получения IQ-отсчётов, построения спектров, усреднения данных и поиска возможных спектральных особенностей.

Основные функции

- Настройка RTL-SDR.
- Получение IQ-отсчётов.
- Преобразование Фурье (FFT).
- Оконная обработка.
- Усреднение спектров.
- Оценка фонового спектра.
- Поиск спектральных особенностей.
- Сохранение результатов.
- Визуализация данных.

Обработка сигнала

Основой спектрального анализа является быстрое преобразование Фурье:

[
X[k] = FFT(x[n])
]

Для уменьшения спектральной утечки применяется оконная функция, например Hann.

Мощность спектральных составляющих может оцениваться через:

[
P[k] = |X[k]|^2
]

Однако такое значение само по себе не является абсолютной мощностью в ваттах или dBm. Для абсолютной калибровки необходима калибровочная процедура.

Настройка приёмника

Один из рассматриваемых вариантов настройки:

Параметр| Значение
Рабочая частота HI| 1420,40575177 МГц
Центральная частота SDR| 1420,105752 МГц
Частота дискретизации| 2,4 MS/s
FFT| 8192
Положение HI относительно LO| +300 кГц

При такой настройке линия HI располагается приблизительно на +300 кГц относительно центральной частоты приёмника.

Это позволяет не размещать её непосредственно около DC-составляющей.

Параметры являются рабочей конфигурацией для экспериментов, а не универсальными настройками для всех режимов наблюдения.

📊 4. Радиометрия и чувствительность

Для оценки чувствительности радиотелескопа используется радиометрическое уравнение:

[
\Delta T = \frac{T_{sys}}{\sqrt{B \cdot \tau}}
]

Где:

- \Delta T — минимальное изменение температуры, которое можно различить в идеализированной модели.
- T_{sys} — системная шумовая температура.
- B — эффективная шумовая полоса измерения.
- \tau — время интегрирования.

Системная температура включает вклад:

- Принимаемого неба.
- Атмосферы.
- Антенны и окружающей среды.
- Кабельных потерь.
- Усилителя.
- Приёмника.

Важно учитывать, что реальная чувствительность может быть хуже теоретической из-за радиопомех, нестабильности усиления, ошибок калибровки и изменений фонового сигнала.

Значения системной температуры и чувствительности в документации следует считать расчётными, пока они не подтверждены измерениями.

🛰️ 5. Автонаведение

Одно из перспективных направлений развития проекта — создание системы автоматического наведения антенны.

Предполагаемые компоненты:

- Arduino.
- Сервоприводы или шаговые двигатели.
- GPS-модуль.
- Механическая азимутально-угломестная платформа.

Планируемые возможности:

- Получение координат наблюдателя.
- Определение положения небесных объектов.
- Управление положением антенны.
- Автоматическое сканирование заданных участков неба.
- Сохранение координат вместе со спектральными данными.

Для полноценного автоматического наведения потребуется учитывать реальные углы положения, механические ограничения, люфт, скорость движения и ограничения на вращение кабелей.

Показания команды приводу сами по себе не подтверждают фактическое положение антенны — для этого необходима обратная связь.

🔬 6. Методика наблюдений

Для поиска линии HI планируется использовать спектральные измерения в разных направлениях неба.

Предполагаемый порядок работы:

1. Проверить питание и подключение радиотракта.
2. Убедиться в стабильной работе RTL-SDR.
3. Настроить центральную частоту.
4. Получить фоновый спектр.
5. Выполнить интегрирование сигнала.
6. Сохранить спектр и параметры наблюдения.
7. Повторить измерение для других направлений.
8. Сравнить полученные спектры.

Для повышения достоверности результатов необходимо:

- Выполнять повторные измерения.
- Сохранять исходные IQ-данные или спектры.
- Контролировать усиление SDR и LNA.
- Учитывать влияние радиопомех.
- Использовать опорные измерения.
- Проверять стабильность частотной шкалы.
- Не путать случайные пики шума с реальными спектральными линиями.

Доплеровское смещение

Движение источника относительно наблюдателя приводит к изменению наблюдаемой частоты линии.

Для небольших скоростей:

[
\frac{\Delta f}{f_0} \approx -\frac{v_r}{c}
]

Где:

- f_0 — лабораторная частота линии.
- \Delta f — частотное смещение.
- v_r — лучевая скорость.
- c — скорость света.

Это позволяет в перспективе оценивать лучевые скорости межзвёздного водорода.

Для корректных научных измерений также необходимо учитывать движение Земли и систему отсчёта, в которой представляется скорость.

⚠️ 8. Ограничения и известные особенности

Проект находится на экспериментальной стадии. При работе необходимо учитывать следующие ограничения:

1. Диаметр параболы около 55 см ограничивает эффективную площадь и угловое разрешение.
2. Реальные характеристики BGA2869 на 1420 МГц требуют экспериментальной проверки.
3. Потери кабелей, фильтров и соединителей влияют на общую чувствительность.
4. RTL-SDR не является специализированным научным радиоприёмником.
5. Наличие спектрального пика ещё не означает обнаружение HI.
6. Радиопомехи могут имитировать полезные спектральные особенности.
7. Абсолютные измерения температуры требуют калибровки.
8. Геометрия фокуса должна быть определена для конкретного отражателя.

Все характеристики следует разделять на:

- "[CALCULATED]" — расчётные значения.
- "[DATASHEET]" — значения из документации производителя.
- "[MEASURED]" — экспериментально измеренные значения.
- "[ASSUMED]" — принятые для расчётов предположения.
- "[NOT VERIFIED]" — неподтверждённые характеристики.
