 Я делаю любительский радиотелескоп для приёма линии водорода 1420 МГц.

  Железо:
  - Парабола ~55 см, глубина 4.5 см, фокус ~40 см
  - BiQuad (двойной квадрат) из медной проволоки
  - LNA BGA2869 (шум 1.9 дБ, усиление 20-32 дБ)
  - RTL-SDR Blog v4
  - Коаксиал RG-58 50 Ом, 3-4 м
  - Фильтр питания: 2×470 мкФ + 100 нФ + 470 нФ + дроссели

  Расчёты BiQuad для 1420 МГц:
  - Сторона квадрата: 5.28 см (λ/4)
  - Общая длина проволоки: ~42 см
  - Рефлектор: 15×15 см, расстояние 1 см
  - Усиление параболы: ~15.7 дБ
  - Общее усиление системы: ~15.7 дБ

  Файлы проекта в папке radio-telescope-project/:
  - readme.txt — описание, комплектующие, этапы сборки
  - calculations.txt — физико-математическая часть с формулами
  - drawing.svg — чертёж
  - dimensions.md — таблица размеров
  - index.html — сайт с анимацией, калькулятором, FAQ

  Дополнительные папки:
  - hydroxyl/ — BiQuad для гидроксила (1665 МГц, сторона 4.5 см)
  - fm-meteors/ — приём метеоров и гроз на FM
  - jupiter/ — приём Юпитера на 18-30 МГц

  Что планируем принимать:
  1. Водород 1420 МГц (Млечный путь)
  2. Гидроксил 1665 МГц (мазеры)
  3. Юпитер (есть рамочная антенна 4-24 МГц)
  4. Метеоры (FM отражение)

  Помоги продолжить проект — уточни детали, добавь код, исправь ошибки.
