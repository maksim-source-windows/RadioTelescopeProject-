на 45° (ромбы), касаются вершиной в точке питания (●●, зазор 3 мм):

```
        /\      /\
       /  \    /  \
      /    \  /    \
     <      ●●      >
      \    /  \    /
       \  /    \  /
        \/      \/

   сторона каждого звена 5.28 см (λ/4)
   диагональ ромба 7.47 см, общая ширина 14.9 см, высота 7.47 см
```

## Размеры параболы (исправлено)

| Параметр | Значение | Примечание |
|----------|----------|------------|
| Диаметр (D) | 55 см | Измеренный |
| Глубина (h) | 4.5 см | Измеренная |
| Фокус (F) | ~42 см (предварительно) | F = (D/2)²/(4h), верно только для симметричной параболы |

**Проверка фокуса:**
- Измерь глубину параболы h
- Вычисли: F = (27.5 см)²/(4 × h)
- Пример: h = 4.5 см → F = 756.25/(4×4.5) = 756.25/18 = 42 см

## Проверка размеров после сборки

1. **BiQuad:**
   - Измерить сторону штангенциркулем = 5.28 см ± 2 мм
   - Проверить симметричность обоих квадратов

2. **Рефлектор:**
   - Убедиться что расстояние до BiQuad ≈ 5.3 см
   - Рефлектор должен быть параллелен BiQuad

3. **Фокус:**
   - [ПРЕДВАРИТЕЛЬНО] F = 42 см рассчитан для симметричной параболы с h = 4.5 см
   - Для ОФСЕТНОЙ ТВ-тарелки (типичной) это значение неприменимо: фокус и направление оси определяются по сигналу (Млечный путь, тест по Солнцу)
   - Начните с ~42 см и двигайте облучатель до максимума сигнала
   - BiQuad должен быть на оси симметрии параболы

---

**ИСПРАВЛЕНИЯ В ЭТОЙ ВЕРСИИ:**
1. Расстояние до рефлектора: 1 см → 5.3 см
2. Фокус параболы: 30/40 см → 42 см (рассчитанный)
3. Размеры диполей: исправлена ошибка "полуволна = четвертьволна"
4. Добавлено замечание о критичности расположения LNA

## Порядок сборки

### BiQuad
1. Проволока 45-50 см (медь 2-4 мм), согнуть два квадрата со стороной 5.28 см (в виде ромбов, касающихся вершиной).
2. Центральную жилу коаксиала припаять к одной точке питания, оплётку - к другой (зазор 3 мм).
3. Оба ромба в одной плоскости, вершины сходятся в точке питания; проверить штангенциркулем (±2 мм).
4. Проверить согласование на 1420 МГц (NanoVNA): КСВ < 2. Подстройка - расстоянием до рефлектора и сторонами.

### Рефлектор
1. Лист 20×20 см минимум: оцинковка, медь или алюминий.
2. Расстояние до BiQuad ≈ λ/4 = 5.3 см, параллельно плоскости BiQuad.

### Крепёж в фокусе
- Можно использовать держатель от ТВ-тарелки.
- [ПРЕДВАРИТЕЛЬНО] F ≈ 42 см (симметричная парабола); для офсетной тарелки положение облучателя находят по сигналу. Предусмотрите юстировку вдоль оси.
- LNA крепить сразу за облучателем (кабель между ними - минимальный).
