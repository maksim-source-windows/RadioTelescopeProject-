===============================================
          БАЗОВЫЕ НАСТРОЙКИ RTL-SDR
===============================================

ПОДКЛЮЧЕНИЕ:
  1. Вставить RTL-SDR в USB
  2. Запустить SDRAngel
  3. Выбрать RTL-SDR в списке устройств

НАСТРОЙКА УСТРОЙСТВА:
  • Sample Rate: 2.4 MS/s (стабильный максимум RTL-SDR, около 2.56 MS/s)
  • Tuner: Auto
  • Gain: начать с 20 dB (LNA уже даёт ~32 dB), поднимать по ситуации
  • PPM: 0 (или калибровать по станции)

===============================================
          НАСТРОЙКА НА 1420 МГЦ
===============================================

ОСНОВНЫЕ НАСТРОЙКИ:

Center Frequency: 1420105752 Hz
  (LO на 300 кГц ниже линии HI 1420.405752 МГц: линия окажется на +300 кГц
  от центра, DC-пик RTL-SDR не мешает; так же настроены скрипты в software/)

Sample Rate: 2400000 Hz (2.4 MS/s)

Диапазон при этой настройке: 1418.906 - 1421.306 МГц

ПРИМЕЧАНИЯ:
• LO смещён на -300 кГц от линии (см. выше), чтобы DC-пик RTL-SDR не перекрывал линию
• SAW-фильтр 1420 МГц: до LNA (защита, +1.5 дБ шума) или после LNA (шум почти не растёт, но LNA может перегружаться); см. calculations.txt, раздел 5.1
• Bias-T на RTL-SDR для питания LNA: включите в настройках устройства (нужен RTL-SDR Blog v4 и его драйвер). Bias-T даёт около 4.5 В, а BGA2869 требует 4.5-5.5 В: проверьте напряжение на LNA, при просадке питайте отдельным 5 В.
  Фильтр в цепи не должен блокировать постоянный ток, иначе питание на LNA не дойдёт.

===============================================
          НАСТРОЙКА СПЕКТРА
===============================================

Открыть: View → Spectrum

ПАРАМЕТРЫ SPECTRUM:
  • FFT Size: 8192 (или 16384)
    - Больше = выше разрешение, но медленнее
    - Рекомендую 8192

  • Window: Hanning (или Blackman-Harris)
    - Меньше боковых лепестков

  • Average: 0.8-0.95
    - 0.95 = сильное усреднение
    - 0.5 = быстрое
    - Для водорода: 0.85

  • Peak Hold: Off (для поиска слабых линий лучше выключить)
    - Peak Hold подходит для стационарных сигналов
    - Для спектральных линий используйте усреднение

  • Line/Filled: Line

===============================================
          НАСТРОЙКА ВОДОПАДА (WATERFALL)
===============================================

View → Waterfall

ПАРАМЕТРЫ:
  • Time per line: 50-100 ms
  • Height: 500-1000 пикселей
  • Color: Hot / Jet / Viridis
  • Auto Floor: On

НАСТРОЙКА:
  • Maximum: -20 dB
  • Floor: -80 dB
  • Gradient: 1.5

===============================================
          НАСТРОЙКА ДЛЯ ВОДОРОДА
===============================================

КРИТИЧЕСКИЕ ПАРАМЕТРЫ:

1. GAIN (усиление)
   - Начните с 20 дБ и поднимайте, пока шум заметно не поднимется над уровнем
     шума АЦП
   - Если на спектре появились паразитные линии или поведение зависит от
     усиления нелинейно, это перегрузка: уменьшите усиление или поставьте
     фильтр первым

2. REFERENCE LEVEL
   - Установите 0 dBFS
   - Это верхняя граница

3. Смещение LO (см. выше): линия на +300 кГц от центра экрана

===============================================
          ИНТЕГРАЦИЯ СИГНАЛА
===============================================

ДЛЯ НАКОПЛЕНИЯ СИГНАЛА:

Способ 1: Встроенное усреднение
  - Spectrum → Average: 0.9-0.95
  - Ждать 5-10 минут

Способ 2: Запись и обработка
  - Record → RAW
  - Потом обработать в Python

Способ 3: Длительный Waterfall
  - Сохранить скриншоты
  - Склеить вручную

===============================================
          ПОИСК ВОДОРОДА
===============================================

ШАГИ:

1. Настроить частоту 1420.405 МГц
2. Направить на Млечный путь
3. Подождать: яркие области Млечного пути 1-3 минуты, слабые 5-15 минут
4. Искать пик на +300 кГц от центра экрана (при LO 1420105752)

ВОЗМОЖНЫЕ ПРОБЛЕМЫ:

❌ Нет пика
  → Проверить усиление
  → Попробовать другое направление
  → Увеличить интеграцию

❌ Пик есть, но слабый
  → Добавить LNA
  → Проверить кабель
  → Убедиться что в фокусе

❌ Много помех
  → Выключить ближайшие устройства
  → Переехать за город
  → Использовать полосовой фильтр

===============================================
            ПРОВЕРКА РАБОТЫ
===============================================

ТЕСТОВЫЕ НАБЛЮДЕНИЯ:

1. Солнце
   - Направить на Солнце
   - Шум должен вырасти примерно на 0.5 дБ (спокойное Солнце, около +45 К при T_sys ~340 К)
   - Это проверка что система работает

2. FM станция
   - На 88-108 МГц
   - Должны быть чёткие пики
   - Проверка что SDR работает

3. Водород
   - 1420.405 МГц, Млечный путь
   - Яркая область Млечного пути: пик через 1-3 минуты накопления
   - Главный тест!
