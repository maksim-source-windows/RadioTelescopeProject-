Для старта — бюджет вполне хватит.
Основные компоненты:
1. RTL-SDR Blog v4 — обязательно оригинал
2. LNA — можно начать с китайского, потом заменить
3. Парабола — сойдёт от ТВ

Докупать постепенно:
- Фильтр → если много помех
- Автонаведение → когда надоест крутить руками
- Второй LNA → когда захочешь улучшить чувствительность
