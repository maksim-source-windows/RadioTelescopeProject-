# История изменений "Радиотелескоп Водород-1420"

## 2026-11-07 (Релиз 20: аудит релиза 19)

Код:
- Новый software/hi_analysis.py: общий анализ для auto_scanner.py и spectrum_recorder.py.
  Раньше базовая линия была просто средним (не линейной), шум считался по std вместе с самой линией,
  порог не использовался. Теперь: линейная МНК-базовая линия по двум опорным полосам, сглаживание 9 бинов,
  шум по разностям независимых окон (MAD), порог обнаружения 6σ
  (на чистом шуме σ ~3, максимум за 300 прогонов 5.0).
- auto_scanner.py: NO_SIGNAL больше не требует pyrtlsdr и pyserial (импорт при подключении), в этом режиме
  SDR и Arduino не открываются; пропущенное наведение не роняет скан (раньше time_avg=None, val=None);
  test_mode реально даёт 3 с на точку; чтение SDR блоками по 64 FFT (быстрее, меньше пропусков);
  спектры в .npz отдельными массивами без pickle, time_tags строками U32; в .npz добавлены sigma и detected;
  astropy: любая ошибка (нет IERS/эфемерид) не прерывает скан; предупреждение, что за скан в часы
  небо поворачивается (~0.25°/мин); matplotlib Agg (работает без дисплея).
- spectrum_recorder.py: тот же анализ, LO 1420105752, предупреждение о коротком накоплении (<60 с).

Исправленные ошибки в документации (остались в релизе 19):
- Рефлектор 15×15 см → не менее 20×20 см (≥ λ), расстояние 5.3 см; BiQuad = два ромба (диагональ 7.47 см).
- calculations.txt: Фрисс с фильтром учитывает кабель (4.61 дБ, 588 К, ΔT 1.07 К); мощность -170.6 дБм

- auto-pointing: в v19 GPS-пины конфликтовали с энкодером (D4 дважды) — исправлено (D4/D5 для GPS);
  внешнее питание серво, isValid(), constrain высоты, сектор азимута 0-180°.

## Известные ограничения
- Нет фильтра 1420 МГц - критично для защиты RTL-SDR от перегрузки (сотовая, WiFi, GPS)
- Нет абсолютной калибровки и полноценного position switching; карта относительная
- Уровень 3 автонаведения (RA/Dec -> Alt/Az) - эскиз
- Серво 0-180° по азимуту; для полного оборота нужен шаговик с редуктором
- Цены в shopping-list ориентировочные (2024 год)
- astropy требуется только для галактических координат (опционально)
