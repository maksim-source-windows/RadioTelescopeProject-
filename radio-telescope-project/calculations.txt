                    РАЗДЕЛ 1. РАСЧЁТ BiQuad
===============================================

1.1. Длина стороны квадрата

Для резонанса BiQuad на частоте f:
    L_side = λ / 4

Подстановка:
    L_side = 21.106 см / 4 = 5.2765 см

Результат:
    L_side ≈ 5.28 см

1.2. Длина проволоки

BiQuad состоит из двух квадратов:
    L_wire = 8 × L_side = 8 × 5.28 см = 42.24 см

Практично: 45-50 см с запасом.

1.3. Рефлектор

Оптимальное расстояние до рефлектора:
    d_ref ≈ λ/4 = 21.106 см / 4 = 5.28 см

Геометрия BiQuad: два квадрата со стороной L_side, повёрнутые на 45° (ромбы),
касаются вершиной в точке питания:
    диагональ ромба = L_side·√2 = 7.47 см
    ширина двух ромбов = 2 × 7.47 = 14.9 см, высота = 7.47 см

Размер рефлектора (минимум): порядка длины волны,
    S_min ≈ λ ≈ 21 см  →  20 × 20 см
Рефлектор 15 × 15 см был бы не больше самого BiQuad (14.9 см) и не работал бы
как рефлектор.

ИСПРАВЛЕНИЕ: ранее было 1 см → теперь 5.3 см

                    РАЗДЕЛ 2. РАСЧЁТ ПАРАБОЛЫ
===============================================

2.1. Фокусное расстояние

Формула параболы:
    F = (D/2)² / (4h)

Подстановка:
    F = (0.275)² / (4 × 0.045) = 0.0756 / 0.18 = 0.42 м

Результат:
    F = 42 см

ПРИМЕЧАНИЕ: Эта формула верна только для симметричной параболы.
ТВ-тарелки чаще офсетные. Фокус лучше измерить по сигналу (Солнце или Млечный путь).

2.2. Усиление параболы

    G_parabola = 10·log₁₀[η·(π·D/λ)²]

Подстановка:
    G_parabola = 10·log₁₀[0.55·(3.14159·0.55/0.21106)²]
               = 10·log₁₀[0.55·(8.19)²]
               = 10·log₁₀(0.55·67.1)
               = 10·log₁₀(36.9)
               = 10·1.567 = 15.67 дБ

Результат:
    G_parabola ≈ 15.7 дБ

2.3. Эффективная площадь

    A_eff = η·π·(D/2)²

Подстановка:
    A_eff = 0.55·3.14159·(0.275)²
          = 0.55·3.14159·0.0756
          = 0.131 м²

ИСПРАВЛЕНИЕ: ранее 0.155 м² (радиус 0.30) → теперь 0.131 м²

2.4. Ширина луча (HPBW)

    θ ≈ 70° × λ / D

Подстановка:
    θ = 70° × 0.21106 / 0.55 = 70° × 0.3837 = 26.9°

                    РАЗДЕЛ 3. ШУМ И ЧУВСТВИТЕЛЬНОСТЬ
===============================================

3.1. Коэффициент шума системы (БЕЗ фильтра)

Перевод в линейные величины:
    F_LNA_lin = 10^(3.1/10) = 2.04
    F_RTL_lin = 10^(8/10) = 6.31
    G_LNA_lin = 10^(32/10) = 1585
    G_cable_lin = 10^(-2.98/10) = 0.501 (потери кабеля 2.98 дБ)

Формула Фрисса (LNA → кабель → RTL-SDR):
    F_total = F_LNA_lin + (F_RTL_lin - 1)/(G_LNA_lin × G_cable_lin)
            = 2.04 + (6.31 - 1)/(1585 × 0.501)
            = 2.04 + 5.31/794
            = 2.04 + 0.0067
            = 2.047

Перевод обратно в дБ:
    F_total_dB = 10·log₁₀(2.047) = 3.11 дБ

Шумовая температура:
    T_radio = 290 × (F_total - 1) = 290 × 1.047 ≈ 304 К
    T_ant ≈ 40 К (принятое предположение: небо + спилловер; реальное значение зависит от направления и определяется измерением)
    T_sys ≈ 304 + 40 = 344 К

ПРИМЕЧАНИЕ: Из-за большого усиления LNA (32 дБ) влияние кабеля после него
сравнительно невелико. При кабеле 2.98 дБ увеличение NF составит ~0.01 дБ.
Критично чтобы LNA был НЕПОСРЕДСТВЕННО у антенны!

3.1b. Коэффициент шума системы (С SAW-фильтром 1.5 дБ)

    F_filter_lin = 10^(1.5/10) = 1.41
    G_filter_lin = 1/1.41 = 0.709 (потери фильтра)

    Фильтр → LNA → кабель → RTL-SDR:
    F_total = F_filter_lin × F_LNA_lin + (F_RTL_lin - 1)/(G_LNA_lin × G_filter_lin × G_cable_lin)
            = 1.41 × 2.04 + 5.31/(1585 × 0.709 × 0.501)
            = 2.88 + 5.31/563
            = 2.88 + 0.0094
            = 2.89

    F_total_dB = 10·log₁₀(2.89) = 4.61 дБ

3.2. Шумовая температура системы

БЕЗ фильтра:
    T_sys_radio = 290·(F_total - 1) = 290·(2.047 - 1) = 290·1.047 ≈ 304 К
    T_sys_sky ≈ 40 К (вклад от неба, спилловер антенны)
    T_sys_total ≈ 304 + 40 = 344 К

С фильтром:
    T_sys_radio = 290·(2.89 - 1) = 290·1.89 ≈ 548 К
    T_sys_total ≈ 548 + 40 = 588 К

3.3. Чувствительность через радиометр

Формула радиометра:
    ΔT = T_sys / √(B·τ)

Где:
    τ = 300 с (время интеграции 5 минут)
    B - эффективная полоса измерения

Разные варианты полосы:
┌─────────────────────────────────────────────────────────────────────┐
│ B (Гц)  │ Вариант                    │ ΔT (БЕЗ фильтра) │ ΔT (SAW) │
├─────────────────────────────────────────────────────────────────────┤
│ 293     │ Один FFT-бин (8192 pts)   │ 1.16 К           │ 1.98 К   │
│ 440     │ Бин × 1.5 (Hann окно)      │ 0.94 К           │ 1.61 К   │
│ 1000    │ Объединение ~3-4 бинов    │ 0.63 К           │ 1.07 К   │
│ 1320    │ 3 бина × 1.5 (Hann)        │ 0.55 К           │ 0.93 К   │
└─────────────────────────────────────────────────────────────────────┘

Пояснения:
• Частотный шаг FFT: Δf = 2.4e6 / 8192 ≈ 293 Гц
• Эквивалентная шумовая полоса окна Hann: ~1.5 × Δf ≈ 440 Гц
• auto_scanner.py: line_half_hz = 200e3 (±200 кГц для поиска пика)
• integration_time = 300 сек (5 минут для сравнения с расчётными значениями)
• ref_offset_hz = 600e3 (опорные полосы на ±600 кГц от центра линии)
• ref_half_hz = 100e3 (ширина опорной полосы 200 кГц)

Для 5-минутной интеграции:
• Теоретическая чувствительность радиометра (B = 1000 Гц): ΔT ≈ 0.63 К
• Чувствительность одного FFT-канала (B ≈ 293 Гц): ΔT ≈ 1.16 К
• Реальная чувствительность алгоритма поиска HI зависит от эффективной полосы
  - Полоса ±200 кГц - это область поиска линии, а не полоса измерения
  - Эффективная полоса - несколько FFT-бинов (~293 Гц на бин, сглаживание 9 бинов ≈ 2.6 кГц)
  - Поиск максимума по ~1365 бинам: на чистом шуме максимум даёт ~3σ,
    поэтому порог обнаружения в software/hi_analysis.py равен 6σ
  - Практический предел определяется не шумом, а стабильностью базовой линии
• Полоса опорных: ~200 кГц → используется для базовой линии

Мощность, соответствующая ΔT (БЕЗ фильтра, B = 1000 Гц):
    P_min = k·ΔT·B = 1.38·10⁻²³ · 0.63 · 1000 ≈ 8.7·10⁻²¹ Вт
    P_min_dBm = 10·log₁₀(8.7·10⁻²¹ / 0.001) ≈ -170.6 дБм

3.4. Практическая интерпретация

Линия водорода имеет яркостную температуру T_b ~50-100 К для ярких областей.
Для обнаружения линии с ΔT = 0.63 К требуется:
- Яркие области Млечного пути: 1-3 минуты
- Холодные облака (T_b ~10 К): 5-15 минут

САМОЕ СУЩЕСТВЕННОЕ ПРЕПЯТСТВИЕ:
- DC-пик RTL-SDR в центре спектра (обходится сдвигом LO на -300 кГц)
- Нестабильность формы полосы пропускания
- Внешние помехи (сотовая, WiFi)

                    РАЗДЕЛ 5.1. ГДЕ СТАВИТЬ SAW-ФИЛЬТР
===============================================

Вариант А: Антенна → Фильтр → LNA → кабель → SDR
    F_total = F_filter × F_LNA = 1.41 × 2.04 = 2.88  (4.6 дБ)
    T_sys ≈ 588 К, ΔT ≈ 1.07 К (B = 1 кГц, 5 мин)
    + LNA защищён от сильных внеполосных сигналов
    - потери фильтра 1.5 дБ прямо добавляются к шуму

Вариант Б: Антенна → LNA → Фильтр → кабель → SDR
    F_total = F_LNA + (F_filter - 1)/G_LNA + (F_RTL - 1)·L_filter/G_LNA
            = 2.04 + 0.41/1585 + 5.31·1.41/1585
            = 2.04 + 0.0003 + 0.0047 = 2.045  (3.11 дБ)
    T_sys ≈ 344 К, ΔT ≈ 0.63 К
    + фильтр почти не ухудшает шум
    - LNA (BGA2869, широкая полоса, 32 дБ) принимает всё подряд и может
      перегружаться сотовой связью, WiFi, ГЛОНАСС/GPS

Рекомендация: в тихом месте (за городом) начинать с варианта Б, в городе или
при признаках перегрузки (паразитные линии на спектре, пик меняется от
усиления) ставить фильтр первым (вариант А) и компенсировать потерю
интеграцией (+1.5 дБ по шуму = ×1.4 по ΔT, т.е. время ×2).

                    РАЗДЕЛ 6.1. ДОПЛЕРОВСКОЕ СМЕЩЕНИЕ
===============================================

Доплеровское смещение линии водорода:
    Δf/f₀ = v/c
где v - скорость газа относительно наблюдателя.

При line_half_hz = 200 кГц:
    v = Δf·c/f₀ = 200e3·3e8/1420e6 ≈ 42.3 км/с

Полоса поиска ±200 кГц соответствует скоростям ±42 км/с (1 км/с = 4.74 кГц).
Линия HI в плоскости Галактики, особенно во внутренней, простирается до
±100 км/с и шире, а движение Земли добавляет до ±30 км/с (±140 кГц).
Поэтому полоса ±200 кГц может обрезать крылья линии: для полного профиля нужна
более широкая полоса, а значит другой сдвиг LO и другие опорные полосы
(ограничение: вся полоса SDR 2.4 МГц, т.е. ±1.2 МГц от LO).
