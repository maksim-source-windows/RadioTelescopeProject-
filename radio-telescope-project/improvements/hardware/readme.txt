===============================================
        1. ПОЛОСОВОЙ ФИЛЬТР НА 1420 МГЦ
===============================================

ЗАЧЕМ:
- Отсечь помехи на других частотах
- Улучшить отношение сигнал/шум
- Убрать FM, сотовые, WiFi помехи

ХАРАКТЕРИСТИКИ:
- Частота: 1420 МГц
- Полоса: ±10-20 МГц
- Затухание в полосе: < 1 дБ
- Затухание вне полосы: > 30 дБ

ВАРИАНТЫ:

А) Готовый фильтр
- Купить SAW фильтр на 1420 МГц
- Цена: 500-2000 ₽
- Подбирайте по параметрам: центр 1420 МГц, потери в полосе < 1.5 дБ

Б) самодельный
- Параметрический резонатор
- Сложно, требует настройки

ПОДКЛЮЧЕНИЕ (варианты, см. calculations.txt, раздел 5.1):
А) Антенна → Фильтр → LNA → SDR   (защита LNA, +1.5 дБ шума)
Б) Антенна → LNA → Фильтр → SDR   (шум ≈ без фильтра, риск перегрузки LNA)

===============================================
           2. ЭКРАНИРОВАНИЕ LNA
===============================================

ЗАЧЕМ:
- Защита от внешних помех
- Уменьшение паразитных наводок
- Стабильность работы

МАТЕРИАЛЫ:
- Медная фольга
- Алюминиевый корпус
- Термоусадка с металлическим слоем

КОНСТРУКЦИЯ:
1. Обмотать LNA медной фолой
2. Запаять все щели
3. Загерметизировать (термоусадка)
4. Заземлить корпус

===============================================
        3. КАСКАДНОЕ ВКЛЮЧЕНИЕ LNA
===============================================

Два LNA последовательно:
LNA1 → LNA2 → Кабель → SDR

РАСЧЁТ ШУМА (формула Фрисса):
F_total = F1 + (F2-1)/G1

Пример:
- LNA1: шум 3.1 дБ, усиление 32 дБ
- LNA2: шум 3.1 дБ, усиление 32 дБ
- F1 = 2.04, F2 = 2.04, G1 = 1585

F_total = 2.04 + (2.04-1)/1585 = 2.04 + 0.00066 = 2.041

Итоговый шум практически не ухудшается!

ПРИМЕЧАНИЕ: Для LNA BGA2869 (NF=3.1 дБ, gain=32 дБ) расчёт аналогичен.

ПЛЮС:
- Можно поставить LNA1 у антенны
- LNA2 у приёмника
- Меньше потерь в кабеле

===============================================
        4. УЛУЧШЕННЫЙ КАБЕЛЬ
===============================================

Текущий: RG-58
- Затухание: ~0.85 дБ/м @ 1.4 ГГц

Варианты лучше:

| Кабель | Затухание @ 1.4 ГГц | Цена/м |
|--------|---------------------|--------|
| RG-58  | 0.85 дБ/м           | 50 ₽   |
| RG-213 | ~0.35 дБ/м          | 100 ₽  |
| LMR-400 | ~0.17 дБ/м         | 300 ₽  |
| HDF-400 | ~0.17 дБ/м         | 250 ₽  |

ПРИМЕЧАНИЕ: Значения затухания ориентировочные, зависят от производителя.

ДЛЯ 3 МЕТРОВ:
- RG-58: потери ~2.6 дБ
- RG-213: потери ~1.1 дБ
- LMR-400: потери ~0.5 дБ
(после LNA потери кабеля почти не влияют на шум, до LNA прямо добавляются к нему)

РЕКОМЕНДАЦИЯ: RG-213 — хороший баланс цена/качество

===============================================
        5. ПРЕДОТВРАЩЕНИЕ ОКИСЛЕНИЯ
===============================================

Проблемы:
- Окисление контактов
- Коррозия разъёмов
- Ухудшение сигнала

Решения:
- Использовать герметичные разъёмы (N-тип)
- Залить соединения силиконом
- Периодическая проверка
- Золотое покрытие разъёмов

===============================================
          6. ИСТОЧНИК БЕСПЕРЕБОЙНОГО ПИТАНИЯ
===============================================

Зачем:
- Стабильное питание LNA
- Защита от скачков напряжения
- Сохранение настроек при отключении

Варианты:
- Для BGA2869 нужно 4.5-5.5 В: 12 В только через стабилизатор 5 В (на голый чип 12 В подавать нельзя)
- USB UPS для RTL-SDR
- Батарейка на Arduino (RTC)
